# swaglabs-selenium-automation

# 🧪 SauceDemo  Automation Framework

A TestNG + Selenium-based automation framework for testing the login functionality of [SauceDemo](https://www.saucedemo.com/v1/) using Page Object Model, Data Providers, Extent Reports, and Screenshot capture on failure.

---

## 🚀 Features

- ✅ Page Object Model (POM) with PageFactory
- ✅ TestNG Framework + DataProvider
- ✅ Extent Reports (HTML) Integration
- ✅ Screenshot on Test Failure
- ✅ Assertion for Login Success & Failure
- ✅ Easily Extendable for More Pages

---

## 🛠️ Tech Stack

| Tool         | Purpose                      |
|--------------|------------------------------|
| Java 17      | Programming Language         |
| Selenium 4   | Browser Automation           |
| TestNG       | Test Execution Framework     |
| ExtentReports| Reporting                    |
| Maven        | Dependency Management        |
| ChromeDriver | WebDriver for Chrome         |

## 🧪 How to Run

### Prerequisites:
- JDK 11 or above
- Maven installed
- Chrome browser
- ChromeDriver path set correctly

### Steps:

# Clone the repository
git clone https://github.com/nuwanthikaishani/swaglabs-selenium-automation

# Navigate to project folder
cd saucedemo-selenium-automation

# Run the tests
mvn clean test
